# Ce16Ox_HDNNP

The final dataset for the Ce<sub>n</sub>O<sub>2n+x</sub> system (n = 16, x = -1, 0, 1) comprises a total of 10,352 structures, including 3,348 Ce<sub>16</sub>O<sub>31</sub>, 3,440 Ce<sub>16</sub>O<sub>32</sub>, and 3,564 Ce<sub>16</sub>O<sub>33</sub> configurations. The dataset is provided in two formates: **n2p2** and **XYZ**, both containing identical structural information. The n2p2 format file can be converted to XYZ format using the provided script ``n2p2_to_extyz.py``.

For details, please refer to this article: Shi, J.; Ren, Q.; Gao, Y. Accelerating Global Optimization of Cerium Oxide Nanocluster Structures with High-Dimensional Neural Network Potential. _J. Phys. Chem. A_ **2025**, _129_, 2190–2199. doi:[10.1021/acs.jpca.4c07840](https://pubs.acs.org/doi/10.1021/acs.jpca.4c07840?ref=PDF).
